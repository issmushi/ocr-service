# История изменений

Коротко о том, что появилось или изменилось в каждой версии сервиса.

## 4.0.0 — 2026-11-17

- Добавлен выбор полей через fields для внутреннего и заграничного паспорта РФ, СНИЛС, водительского удостоверения, ЕГРН и MRZ. По умолчанию all возвращает все поля. Можно передать несколько fields или список через запятую; незапрошенных полей в JSON нет, meta остаётся всегда.
- Для визуальных документов распознаются только выбранные области и общие для них вырезки. Поиск документа и полей выполняется целиком. MRZ по-прежнему читается полностью, а fields ограничивает только состав ответа. Выбор работает и в задачах.
- В ответ внутреннего паспорта добавлено место рождения — birth_place_ru. Оно также доступно для выбора в API и UI.
- ЕГРН расширена с пяти до 19 полей: все 17 значений таблиц первой страницы, номер заявления и дата актуальности. Добавлены их вырезки, распознавание и выбор в UI. Поддерживается текущий макет выписки Госуслуг с двумя строками верхней таблицы и 15 строками характеристик; другие макеты пока не поддерживаются.
- В Swagger операции разделены на MRZ Sync / Async, Russia Sync / Async, Full Sync / Async и Crop Sync / Async. В Tasks остались только статус, получение результата и отмена задачи.
- Добавлены задачи /v1/tasks/crop/egrn и /v1/tasks/crop/egrn-fields. Все четыре операции Crop имеют асинхронный вариант с теми же параметрами и результатами.
- Удалены /v1/ocr/crop/document-fields, /v1/tasks/crop/document-fields и инструмент «Поля документа» в UI. Распознавание документов и вырезка полей ЕГРН сохраняются.
- Получение результата задачи поддерживает PNG наряду с JSON и JPEG. Обрезанная страница ЕГРН возвращается без дополнительного JPEG-сжатия.
- Из MRZ удалены параметр crop и предварительная обрезка, выравнивание и поворот: исходное изображение передаётся напрямую в MRZ Scanner. Это работает в Sync и Async, включая ранее созданные задачи; Paddle для распознавания MRZ больше не нужен. При необходимости подготовку изображения можно выполнить отдельным Crop-запросом.
- Удалены генерация и распознавание QR, связанные настройки, ключи и проверки Health. Интеграции, использовавшие QR-маршруты или встроенную обрезку MRZ, нужно обновить. Остальные адреса API сохраняют префикс /v1.
- Обновлены документация в UI и инструкция интеграции ЕГРН. Для новых типов Crop-задач добавлена миграция базы данных; при обновлении сервера требуется выполнить alembic upgrade head.

## 3.1.0 — 2026-11-06

- Добавлено распознавание первой страницы выписки ЕГРН через раздел Russia и очередь Tasks. Оба способа возвращают номер заявления, кадастровый номер, адрес, наименование и дату актуальности.
- В UI можно загрузить скан, проверить границы пяти полей и сравнить чтение через Paddle Cyrillic и Paddle eslav.

## 3.0.0 — 2026-10-22

- Добавлена проверка UV-признаков подлинности внутреннего паспорта РФ: результат, подробные проверки и время обработки.
- RussianDocsOCR обновлён с 4.6.1 до 4.8.1. Обновлены модели поиска документа, определения ориентации и полей.
- Маршрут вырезки полей /v1/ocr/crop/passport-fields заменён на /v1/ocr/crop/document-fields. Для существующих интеграций нужно заменить адрес запроса.
- Уточнены названия разделов интерфейса: «Распознавание полного текста» и «Поля документа». Описание вырезки областей больше не ограничено третьей страницей паспорта.

## 2.0.0 — 2026-10-02

- MRZ паспортов и ID-карт теперь распознаётся через единый запрос.
- Добавлено распознавание загранпаспорта РФ, СНИЛС и водительского удостоверения.
- Улучшено чтение полей внутреннего паспорта РФ и проверка дат в российских документах.
- В интерфейсе можно проверить новые документы и сравнить модели на вырезанных полях паспорта.
- Изменились адреса запросов и имена полей в MRZ-ответе; существующие интеграции нужно обновить.
